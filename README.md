# Financial News Stock Market Sentiment Analysis

## Overview

This project analyzes financial news headlines and estimates their
sentiment in order to understand how news tone may relate to stock
market behavior.\
The notebook demonstrates a simple workflow that includes data loading,
preprocessing, sentiment analysis, and visualization.

The goal of the project is educational --- to show how natural language
processing (NLP) techniques can be applied to financial news data.

------------------------------------------------------------------------

## Features

-   Loads and processes financial news headline data
-   Applies sentiment analysis to classify news tone
-   Visualizes sentiment distribution
-   Demonstrates a basic end-to-end NLP workflow
-   Implemented in Python using commonly used data science libraries
